# GARUDA_cubsat
G.A.R.U.D.A. (Ground-link Automated Receiver &amp; Unified Data Analyzer) is a browser-based CubeSat ground station by Niranjan CS. Over Web Serial, it integrates pre-flight hardware calibration, reaction wheel testing, and live LoRa telemetry with 3D visualization, mapping, graphing, and auto-stamped CSV, JSON, and Excel exports.
